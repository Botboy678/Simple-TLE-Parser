# Simple-TLE-Parser

A simple parser for NORAD Two-Line Element Set Format data.

## Description

This tool parses TLE (Two-Line Element) sets, the standard format used by NORAD and NASA to describe orbital elements of Earth-orbiting objects. The parser extracts the raw data from TLE strings, making it accessible for further processing and analysis.

## Data Source

TLE data can be obtained from: [CelesTrak](https://celestrak.org/NORAD/elements/)

## Current Features (v1.0)

- Extracts all data fields from standard TLE format
- Provides access to raw orbital parameters
- Simple, lightweight implementation

## Upcoming Features (v2.0 - coming soon)

- Convert raw data to human-readable format with proper units
- Display dates in standard calendar format
- Provide descriptive labels for all orbital parameters
